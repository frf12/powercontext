Cost guidance: every tool call re-sends the whole conversation, so the number of steps dominates cost. Plan before acting: locate the relevant code with one or two targeted searches, read only the line ranges you need and batch independent reads into a single command, then make the complete change in as few edits as possible. Run the most relevant tests once; do not spend many steps repairing the test environment, a targeted compile or import check is acceptable when tests cannot run.
